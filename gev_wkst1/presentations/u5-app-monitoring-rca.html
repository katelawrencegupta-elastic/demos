    Use case 5Agent Builder

    From application alert to grounded RCA in Elastic

    When checkout-api fails for acme-retail, Agent Builder elasticco-rca-agent calls ES|QL tools (error rate, FOR UPDATE, OOM, orchestrator retries, SLO posture). The human says “approve rollback to v2.4.0.” If Cases/email capabilities exist, the agent writes the case; otherwise paste into the open Observability case. The Python CLI is a facilitator backup — not the customer close.
