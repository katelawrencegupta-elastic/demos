    Use case 5RCA agent

    From application alert to approved remediation and on-call email

    When checkout-api error rate crosses 10%, the RCA agent correlates APM, Kubernetes, orchestrator logs, and checkout logs — posts triage to a Kibana case, waits for human approval (or runs auto), rolls back v2.4.1 → v2.4.0, and emails the incident summary.

    Application monitoring is not just a chart — it is an automated runbook that keeps humans in the loop, writes an audit trail, and notifies on-call with evidence.

    Application monitoring alert

    elasticco-app-checkout-error-rate fires when checkout-api transaction failures exceed 10% over 15 minutes — service-level, not infrastructure noise.

      Human approval vs automatic remediation
      
            
      Customer demos often show human-in-the-loop; scripted endings use --auto.
      
          
      
          
      
            
      
              
      Human approval (default)
      
              
      python -m src.cli incident \
  --email kate.lawrencegupta@elastic.co
      
              
        
                
      • Agent prints RCA + remediation plan
        • 
                
      • Prompt: Approve remediation? [y/N]
        • 
                
      • On y: rollback log, case closed, email sent
        • 
                
      • On n: case left open, no changes
        • 
              
      
            
      
            
      
              
      Automatic (--auto)
      
              
      python -m src.cli incident \
  --auto --email kate.lawrencegupta@elastic.co
      
              
        
                
      • Skips approval prompt
        • 
                
      • Records approver as rca-agent-auto
        • 
                
      • Good for tight demo endings
        • 
                
      • --dry-run investigates only — no side effects
        • 
              
      
            
      
          
      
          
      
            Facilitator tip
            
      Run --dry-run first to show evidence without changing the cluster. Then run the live command for approval + email.
