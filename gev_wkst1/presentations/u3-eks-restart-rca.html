    Customer outcome

    Narrate restart → reason in under 60 seconds using evidence fields: kubernetes.event.reason, kubernetes.pod.restart.count, service.version, and CartCache.retainAll.

    Symptom vs reason

    On-call often stops at “the pod restarted.” Elastic lets you keep going: memory vs limit, the kill event, the app log, the deploy.

    What kubectl shows

    • RESTARTS 4 — a counter, not a cause
    • Last state OOMKilled if you still have the pod
    • No deploy version, no tenant, no trace
    • Gone after the next rollout

    What Elastic keeps

    • Memory climb vs 512 MiB limit over time
    • OOMKilled then BackOff events
    • Container log: OutOfMemoryError + deploy=2.4.1
    • Same timestamps as U2 FOR UPDATE spans
